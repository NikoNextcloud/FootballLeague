# А Група

Модерно уеб приложение за българската Първа лига: предстоящи мачове, резултати, публикувано класиране, профили на отборите и българското участие в Европа.

Работещ адрес: https://nikonextcloud.github.io/FootballLeague/

Приложението е статично и работи без backend, платен API или клиентско извличане от чужди сайтове. Има адаптивен интерфейс, инсталиране като PWA и последно успешно копие за работа без интернет.

## Как се обновява

1. GitHub Actions проверява източника на **15 минути**, в :07, :22, :37 и :52. Графикът на GitHub може да закъснява.
2. Python ботът извлича и проверява `data/bulgarian-football.json` от [bulgarian-football.com](https://bulgarian-football.com/parva-liga.html).
3. Запазва публикуваните точки и позиции. Не ги заменя със собствено сортиране по голова разлика или сбор от победите.
4. Проверява статистиката на всеки отбор спрямо наличните резултати. При разминаване показва предупреждение и запазва таблицата на източника.
5. След успешна проверка workflow публикува новия сайт изрично в Pages. Само commit с `GITHUB_TOKEN` не стартира branch Pages build.
6. Отвореното приложение проверява JSON на **5 минути**, при връщане към таба и при възстановяване на връзката. Бутонът ↻ проверява веднага публикувания JSON; не стартира сървърния бот.

Екранът показва датата на **успешното извличане от източника**, а не часа на отваряне на страницата. След шест часа без успешна проверка данните се обозначават като остарели. Това е периодично обновявана програма и статистика; външен линк към AiScore е наличен за резултати на живо.

## Точност и устойчивост

- Сезонът се извлича от заглавието на източника; списъкът на клубовете идва от таблицата.
- Всички кръгове, включително XI–XXVI, се разпознават. Мачовете без обявен час остават видими като „Час предстои“.
- Пренасрочен мач запазва кръга и идентичността си. Повтарящи се записи се обединяват; противоречиви резултати се отхвърлят.
- Началните часове и напомнянията използват **Europe/Sofia**, включително лятното часово време, независимо къде е устройството.
- Минал начален час не означава завършил мач или потвърден статус „на живо“.
- Неуспешно основно извличане/проверка не презаписва последния валиден файл. Записът е атомичен.
- При временно недостъпен европейски източник секцията пази собствената си дата и предупреждение. Данни от предишен сезон не се пренасят в новия.
- Невалиден или забранен localStorage не спира стартирането. Обновяването запазва незавършения текст във формите.
- Офлайн кешът запазва последните успешни отговори, отличава ги от мрежовите и не презаписва с HTTP грешки.

## Локално отваряне

Стартирайте `start-local.bat` в Windows или:

```sh
python -m http.server 8000
```

Отворете http://localhost:8000. Няма build стъпка или runtime npm зависимости.

## Проверки

Python 3.12+ и Node 22+:

```sh
python -m unittest discover -s tests -v
python scripts/bulgarian_football_bot.py --validate-only
node --test tests/*.mjs
node --check app.js
node --check football-data.js
node --check service-worker.js
```

За опционалните реални браузърни и автоматизирани проверки за достъпност:

```sh
npm install --no-save playwright @axe-core/playwright
npx playwright install chromium
CHECK_ACCESSIBILITY=1 node tests/browser-smoke.cjs
```

При наличен браузър задайте `CHROMIUM_PATH`. Снимките се записват във временната директория на операционната система. Подробности, обхват на проверките и оставащи ограничения: [docs/quality-review.md](docs/quality-review.md).

За реално обновяване от източника:

```sh
python scripts/bulgarian_football_bot.py
```

`fetch-data.mjs` и `data/2026-2027.json` са запазени наследени материали. Активното приложение и автоматичният workflow използват само `data/bulgarian-football.json`.

## GitHub Pages

В Settings → Pages изберете **GitHub Actions** за publishing source. Workflow задава `pages: write`, `id-token: write`, deployment environment `github-pages` и отделен пакет само с публичните файлове. PR изпълнява проверките, без да публикува; сливането в `main`, ръчното стартиране и успешното планирано обновяване публикуват сайта.

## Напомняния и външни услуги

Камбанката включва напомняния за планирания начален час, докато приложението е отворено. Известия при затворено приложение и известия за гол не се предоставят. Външните live услуги имат собствена достъпност и условия.
