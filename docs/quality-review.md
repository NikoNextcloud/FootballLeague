# FootballLeague — проверка на обновяването

## Цел и план

Промяната обхваща модерния интерфейс и целия път на футболните данни: източник → парсер → проверен JSON → GitHub Pages → браузър → последно валидно офлайн копие.

Работата премина през четири паралелни направления: проучване на източници, одит/ремонт на парсера и workflow, дизайн и адаптивност, PWA и офлайн устойчивост. След реализацията са направени отделни повторни прегледи на новия код, сезонните преходи, часовите зони, съгласуваността на статистиката и достъпността.

## Открити и поправени проблеми

| Проблем | Резултат от промяната |
|---|---|
| Римски кръгове след X не се разпознаваха | Разпознават се всички публикувани кръгове |
| Мачове без начален час се пропускаха | Остават видими с изрично неизвестен час |
| Пренасрочен мач се дублираше под грешен кръг | Стабилна идентичност и актуална дата |
| Класирането можеше да се пресмята по голова разлика | Запазва се публикуваният ред и точките |
| Календарният час създаваше недоказан LIVE статус | Няма автоматично LIVE твърдение само по часовник |
| Europe включваше чужди срещи без българско участие | Показва само действителните български участници |
| Архив можеше да подмени таблицата за текущия сезон | Няма мутация на текущите данни от архивни файлове |
| Повреден/забранен localStorage сриваше стартирането | Проверка на схемата и мрежово възстановяване |
| Всеки успешен fetch се обозначаваше като актуален | Свежест според реалната успешна проверка на източника |
| Офлайн JSON оставаше от деня на инсталирането | Кешът се обновява с успешните отговори |
| HTTP грешка можеше да наруши офлайн данните | Запазва се последното успешно копие |
| Версионираните JS URL не съвпадаха с offline precache | Канонични кеш ключове и helper в precache |
| Автообновяването губеше незапазен текст и фокус | Запазва се черновата и се възстановява фокусът |
| Постоянната навигация натрупваше click listeners | Един делегиран listener |
| Пълната таблица скриваше статистики на телефон | Всички колони са достъпни с хоризонтално превъртане |
| Скролируемата таблица не се достигаше с клавиатура | Фокусируем регион с достъпно име |
| Само bot commit не публикуваше новите данни | Explicit Pages deploy със съответните права |

## Проверен реален набор

При реалното извличане на 19.10.2026 източникът предостави сезон 2026–2027:

- 14 отбора и 182 срещи в 26 кръга;
- 76 приключили срещи;
- 70 срещи без потвърден начален час — запазени с празен час;
- 38 европейски срещи с българско участие;
- 108 голмайстори.

За всички 14 отбора изиграните срещи, победите, равенствата, загубите и вкараните/допуснатите голове съвпадат с резултатите. Точките и позициите не са променяни от алгоритъм. Те са съпоставени и с публикуваното класиране на efbet Лига. Броят на срещите е факт от тази проверка, а не постоянна настройка в приложението.

## Допълнителна итерация: скорост и сигурност

След първия завършен вариант е направен отделен преглед на ресурсите и сигурността. Логото за 54px е заменено с умалено WebP копие на същия знак, вместо да зарежда оригиналния PNG от 1,14 MB. Оригиналът е запазен като изходен материал. Проверени са ограничението на URL схемите, HTML escaping, външните връзки, обхватът и размерът на кеша.

## Автоматизирани проверки

- 16 Python регресии: римски кръгове, дати без час, обща дата за няколко срещи, пренасрочване, противоречиви резултати, запазване при грешка, атомичен запис, европейски обхват, преход към нов сезон и съгласуваност.
- 15 Node регресии: резултати с липсващи стойности, DST за Europe/Sofia, бъдещи/отложени срещи, свежест, повреден кеш и поведение на service worker.
- Реален Chromium: 1440, 768, 390 и 320px; без хоризонтално излизане на документа.
- Браузър в Pacific/Honolulu: датите и началните часове остават български.
- Навигация, пълно класиране, всички кръгове, филтър за отбор, клавиатурно разгъване на статистика, профил на клуб и Europe.
- Презареждане без интернет и възстановяване при връщане на връзката.
- Невалиден кеш и отказан достъп до localStorage.
- Едновременно обновяване се изпълнява веднъж; непубликуван текст остава във формата.
- Симулирана корекция на публикувани точки се показва точно; невалидна нова таблица се отхвърля.
- Автоматизиран axe-core одит за WCAG 2 A/AA и WCAG 2.1 AA: Начало, Класиране, Мачове, Отбори и Европа без открити нарушения. Това не заменя пълен ръчен одит с помощни технологии.

## Ограничения и публикуване

- Извличането е на 15 минути, а проверката от отворения браузър — на 5. GitHub Actions и самият източник могат да закъсняват; не се обещава резултат за всеки гол в реално време.
- Проверка на източника е различна от това източникът да е обновил своето съдържание. Часът в приложението обозначава успешното извличане.
- Официалните точки имат предимство при административни корекции. Разлика спрямо резултатите се обозначава, без да се измисля „коригирано“ класиране.
- При промяна на HTML структурата или плейофния формат защитата може да спре обновяването. Последните валидни данни остават и след шест часа се обозначават като остарели.
- Конкурентна промяна в `main` може безопасно да откаже bot push. Следващият планиран опит използва новата основа.
- Напомнянията изискват отворено приложение; затворени push известия не са внедрени.
- Source настройката на Pages трябва да бъде GitHub Actions. PR проверките не публикуват. Реалното ново production публикуване и следващ планиран production run трябва да се проверят след сливане.
